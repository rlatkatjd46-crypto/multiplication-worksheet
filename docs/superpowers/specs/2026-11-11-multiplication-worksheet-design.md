# Spec: 초등학교 2학년 두 자릿수 X 한 자릿수 곱셈 세로셈 학습지 웹 앱

## 1. 개요 및 목표
초등학교 2학년 2학기 곱셈 단원의 '두 자릿수 × 한 자릿수' 세로셈을 연습할 수 있는 웹 기반 인터랙티브 학습지 및 인쇄용 학습지 시스템.

## 2. 디자인 및 테마 사양
- **톤 & 매너**: 포근함, 순수, 아기자기함, 동화 감성
- **배경 색상**: `#FFF5F5` (베이비 핑크 화이트)
- **본문 텍스트**: `#7B6B8D` (소프트 라벤더 그레이)
- **강조 색상**: `#FFB5C2` (베이비 핑크), `#B5D8F7` (베이비 블루)
- **그림 및 장식**: SVG 기반 구름, 별, 달, 토끼, 곰 인형, 풍선 장식 및 폭신한 그림자
- **타이포그래피**: 둥근 고딕/손글씨 웹폰트(Gaegu, Dongle 등 구글 폰트 적용), 큼직한 글씨 크기와 넉넉한 줄 간격

## 3. 학습지 구성 및 수학적 사양
- **페이지 구성**: 5페이지 (페이지당 9문제, 총 45문제) + 답안지 페이지
- **문제 규격**:
  - 두 자릿수 (11 ~ 99) × 한 자릿수 (2 ~ 9)
  - 올림이 없는 곱셈과 올림이 있는 곱셈 균형 있게 생성
- **세로셈 구조**:
  ```text
        [ 1 ][ 9 ]
     ×       [ 3 ]
    ---------------
        [ 2 ][ 7 ]   (9 × 3)
     [ 3 ][ 0 ]      (10 × 3)
    ---------------
     [ ][ 5 ][ 7 ]   (최종 결과: 57)
  ```
- **상호작용 기능**:
  - 각 빈칸에 숫자 1자리 입력 및 자동 다음 포커스 이동, 백스페이스 시 이전 칸 이동
  - 페이지 이동 네비게이션 (1~5페이지, 답안지 탭)
  - '새 문제 생성': 클릭 시 45문제 즉시 새로 무작위 생성
  - '채점하기': 입력한 답안의 정답/오답 확인 및 참 잘했어요 스탬프
  - '정답 보기': 풀이 단계별 정답 즉시 표시 토글
  - '인쇄하기': A4 용지 규격에 맞게 1~5페이지 및 답지가 페이지별로 깔끔하게 인쇄되도록 `@media print` 스타일 적용

## 4. 기술 스택 및 배포 사양
- **기술 스택**: 순수 HTML5, CSS3, Modern JavaScript (Vanilla JS, No external build dependency to ensure perfect GitHub Pages static hosting)
- **저장소 및 배포**:
  - Git 초기화, 커밋
  - GitHub CLI (`gh`)를 통한 원격 리포지토리 생성
  - GitHub Pages 설정 및 배포 자동화
